WINDOWS PAR START
1. ZIP ko poora Extract All karein. ZIP ke andar se direct run na karein.
2. Python 3.13 installed hona chahiye. Official installer python.org se lein aur
   installation mein 'Add Python to PATH' tick karein.
3. Pehle dekhne ke liye START_DEMO_WINDOWS.bat double-click karein.
   Asal empty workspace ke liye START_WINDOWS.bat use karein.
4. Pehli dafa launcher dependencies install karta hai, isliye internet chahiye.
5. Browser localhost:8787 par khulega. Server window mein ONE-TIME SETUP CODE hoga.
6. Apna naam, email, 14+ characters ka password aur setup code enter karein.
   Koi default admin password nahi hai. Setup code/private secrets share na karein.
7. Server window open rakhein. Browser band karne se worker nahi rukta, lekin PC
   shutdown ya server process band karne se sync ruk jata hai.

GOOGLE SHEETS CONNECT KARNA
docs/GOOGLE_SETUP.md follow karein. Apna OAuth client local .env mein configure
karna aur apni Google identity authorize karna zaroori hai. Google password app
mein enter nahi karna. Chat mein client secret/keys na bhejein.
Sheets Restricted/private hi rahengi. Koi public editor link required nahi.
Har store ki actual columns/header mapping alag inspect karein; columns assume
nahi hotay. Pehle read-only import aur reconciliation.
Write-back ke liye MFA, test Sheet verification, safe field ownership aur explicit
owner approval required hain. Arbitrary shared cells ko blind overwrite nahi karta.

SECURITY / BACKUP
Security > authenticator MFA enable karein aur recovery codes offline save karein.
Settings > encrypted backup. .data/backup-recovery.key ko backup se alag secure
jagah par rakhna zaroori hai. Key ke baghair encrypted backup restore nahi hota.
Restore sirf nayi empty directory mein hota hai aur writes disabled rehti hain.
Detailed guide: docs/OPERATIONS.md.
